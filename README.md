# Harshit AI Tutor

An AI English-learning tutor created by Harshit Tiwari.

## Features

- English speaking practice
- Grammar correction
- Vocabulary
- Daily conversation
- B1 interview practice
- Hindi-to-English support

## Deployment

This app is designed for Streamlit Community Cloud.
Keep API keys out of GitHub and add `OPENAI_API_KEY` through Streamlit Secrets.
